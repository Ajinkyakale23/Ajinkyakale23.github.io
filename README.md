# Ajinkya Kale — GitHub Pages Resume

This repository is a static personal resume/portfolio website.

## Publish it

1. Create a GitHub repository named **Ajinkyakale23.github.io**.
2. Upload `index.html`, `style.css`, and `resume.pdf` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will be available at:
   `https://Ajinkyakale23.github.io/`

GitHub Pages may take a few minutes to publish changes.

## Files

- `index.html` — website content
- `style.css` — responsive styling
- `resume.pdf` — downloadable ATS resume
